# Realistic Polish Diesel Price

Skrypt dodaje menu pozwalające na zmianę ceny diesla w oparciu o prawdziwe kraje. Ponad 35 państw w kategoriach. 
Jak używać: Przejdź do ustawień gry, znajdź "Realistic Diesel Price", wybierz region, a następnie kraj. Zmiany wprowadzane są natychmiast.
Zakup paliwa w stacjonarnym zbiorniku jest droższy niż na stacji. Obsługuje tryb wieloosobowy.
